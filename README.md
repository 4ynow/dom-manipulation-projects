# DOM Manipulation Projects

A collection of four interactive front-end projects built with HTML, CSS, and vanilla JavaScript. Each project is self-contained and focuses on clean, readable code and responsive behavior without frameworks or libraries.

## Projects

| Project | Description 
|---|---
| Quote Generator | Displays a random quote and its author on each click. 
| Accordion (FAQ)| An expandable FAQ list where each item toggles open and closed. 
| Stopwatch | A stopwatch with start, stop, and reset controls. 

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/4ynow/dom-manipulation-projects.git
cd dom-manipulation-practice
```
